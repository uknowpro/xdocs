# xcode 세션

워크스페이스의 **xcode 세션 만들기** 또는 폴더의 **+ → xcode 세션**으로 시작한다. **세션 설정 펼치기**에서 API 주소(Chat Completions 전체 주소), API 토큰(선택), 모델명을 입력한 뒤 메시지를 전송한다. 모델명은 서버가 노출하는 모델 ID다. 기본 주소는 `http://127.0.0.1:8000/v1/chat/completions`다. 원격 서버에는 HTTPS를 사용한다. 고급 설정에서 기존 Builder 모델 프로필 선택, 동시 요청 수, 연결 진단, 자동 재요청, 하네스를 조정할 수 있다. 직접 입력한 API 키는 세션 노트에 저장하지 않는다.

## settings.json으로 연결하기

**세션 설정 펼치기 → JSON 설정**에서 직접 붙여넣거나 **설정 파일 불러오기**로 파일을 선택한 뒤 **JSON 적용**을 누릅니다. 적용한 값은 기본 설정과 고급 설정에도 반영됩니다.

```json
{
  "endpoint": "http://127.0.0.1:8000/v1/chat/completions",
  "model": "my-model",
  "autoRetry": true,
  "retrySeconds": 60,
  "maxAutoRequests": 3
}
```

필수 항목은 `endpoint`와 `model`입니다. 인증이 필요하면 문자열 `token`을 추가하세요. **현재 설정 내보내기**는 토큰을 제외한 적용값을 저장합니다. 같은 주소에서 토큰을 생략하면 현재 토큰을 유지하고, 주소를 바꾸면 이전 토큰을 지웁니다. 선택 항목 `autoRetry`와 `repeatCompleted`는 true/false, `retrySeconds`는 1–3600초, `maxAutoRequests`는 1–100회, `autoMinutes`는 1–240분입니다. 생략한 재요청 옵션은 기존 값을 유지합니다.

잘못된 JSON이나 범위를 벗어난 값은 적용 전에 표시됩니다. 전송 시 401/403이면 토큰·권한, 404이면 주소·모델명을 확인하세요. 400/422이면 고급 설정의 텍스트 연결 진단으로 기본 요청을 먼저 확인한 후 이미지·PDF와 추론 옵션을 확인하세요.

사이드바를 접으면 현재 워크스페이스의 xcode 세션이 두 개 이상일 때 상단의 세션 이름으로 대화를 전환할 수 있습니다.

## 대화와 첨부

전송하면 지정한 서버가 SSE로 돌려주는 답변을 표시한다. 중지할 수 있으며 완료한 요청·첨부 참조·단계별 결과는 워크스페이스 페이지에 저장한다. 다음 요청은 기본적으로 이전 대화와 첨부를 다시 포함한다. 하네스에서 최근 대화 수를 지정하면 전송 범위를 줄일 수 있다. 이미지·PDF 원본은 보관함 첨부에 보관하며, 공유 워크스페이스에서는 해당 공간의 동기화 정책을 따른다.

| 입력 | 서버에 보내는 형식 |
| --- | --- |
| UTF-8 소스·Markdown·CSV·로그 | 파일명과 텍스트 |
| DOCX·PPTX·XLSX | 단락·슬라이드 텍스트 또는 셀 주소와 저장된 값. 도형, 임베디드 이미지, 수식 재계산은 제외 |
| PNG·JPEG·WebP·GIF | 이미지 입력을 지원하는 서버에 Chat Completions의 image_url 데이터로 전달 |
| PDF | file_data를 지원하는 서버에 원본 전달. 서버의 PDF 처리 능력에 따라 사용 가능 |

파일 선택과 끌어놓기를 지원한다. 클립보드의 이미지는 메시지 영역에 붙여넣는다. 텍스트 문서는 파일당 8MB 및 추출 후 16만 자, 이미지·PDF는 파일당 12MB, 모델 요청은 전체 32MB가 상한이다.

## 병렬 실행과 자동 재요청

같은 워크스페이스에서 페이지마다 독립적인 요청을 실행한다. 페이지를 바꾸어도 응답은 원래 페이지에 저장된다. 사이드바의 **실행 중인 xcode 세션**에서 돌아가 진행 상태를 확인하거나 해당 요청만 중지할 수 있다. 앱을 닫거나 워크스페이스를 바꾸면 실행과 예약은 종료된다.

자동 재요청은 기본으로 꺼져 있으며 설정은 페이지별로 저장된다. 기본 간격은 60초다. **중단된 응답만 이어받기**는 일시적인 서버 오류, 연결 끊김, 출력 길이 제한 후 이미 받은 텍스트와 함께 ‘계속해주세요’를 보낸다. **정상 완료 후에도 계속 요청**은 하네스를 마친 뒤에도 간격마다 같은 대화에 ‘계속해주세요’를 보내며, 완료된 답변을 하나씩 저장한다. HTTP 429, 사용량·잔액 초과, 인증 실패 등은 자동으로 반복하지 않는다. 재요청을 끄면 다음 예약이 취소되고, **중지**는 실행 중인 요청도 취소한다.

## 하네스

직접 대화, 코드 검토, 인프라 변경 검토, 이미지·문서 분석, 기술 설계 중 하나에서 시작한다. 단계를 추가·삭제·재정렬하고 각 단계의 지침을 편집한다. 한 번 전송할 때마다 단계별로 모델을 호출하며 다음 단계는 앞선 단계의 답을 받는다. 서버 기본 추론 강도를 사용하거나 지원되는 값을 명시할 수 있다. 템플릿을 바꾸면 현재 하네스 구성이 교체된다. 하네스 JSON 내보내기·가져오기로 다른 세션에서 재사용할 수 있다.

**.claude 스킬 찾기**는 사용자 홈과 로컬 워크스페이스의 `.claude/skills/<이름>/SKILL.md`를 찾는다. 추가한 지침의 사본이 하네스에 저장되고 모델 요청에 포함된다. 스킬의 부속 스크립트·훅 실행, 셸 및 프로젝트 파일 자동 수정은 이 버전의 실행 범위 밖이다.

## DeepSeek 업무별 기본 구성

새 세션은 단일 호출로 근거 기반 답변을 작성한다. 변경안 작성과 인프라 의사결정에는 근거 추출, 설계·작성, 검토 세 단계를 제공한다. 시각 자료 판독은 관찰과 해석 두 단계다. 추출·관찰 단계에 low, 작성·판단·검토 단계에 high를 지정한 것은 xdocs의 업무별 설계 선택이다. 하네스와 각 단계에서 변경할 수 있으며, 추론 옵션을 받지 않는 서빙 엔드포인트는 단계별로 **서버 기본값**을 선택한다.

같은 요청의 여러 단계는 스킬, 전체 단계 지침, 과거 대화와 첨부를 같은 순서로 공유한다. 뒤 단계에서는 앞 단계의 답과 다음 단계 번호를 이어 붙인다. 이 구조는 prefix caching이 활성화된 서빙 엔진에서 공통 입력을 재사용할 수 있게 한다. 실제 캐시 사용 여부는 서버 설정에 달려 있다. 이전 턴에서는 최종 답을 넘긴다. 도구 호출 없는 텍스트 대화에는 모델 내부 추론 텍스트를 재전송할 필요가 없다.

## 전송 및 자동 요청 관리

앱을 실행한 후 처음 사용하는 모델 주소는 전송 전에 확인합니다. 허용은 해당 주소에만 적용되며 앱을 종료하면 초기화됩니다. 자동 요청 횟수는 직접 전송할 때마다 새로 계산합니다. 오류 재시도와 정상 완료 후 이어쓰기가 같은 한도(기본 5회)를 사용합니다. 사이드바의 실행 중인 세션 목록에서 현재 워크스페이스의 모든 요청과 대기를 중지할 수 있습니다.

전송 버튼 옆의 **전송 미리보기**에서 주소와 모델을 확인하고, 이번 요청에 포함할 이전 대화·이전 첨부·새 첨부·스킬을 선택할 수 있습니다. 제외한 새 첨부는 입력란에 남습니다. 각 요청의 결과에는 실행 당시 모델, 하네스와 스킬 이름, 단계별 추론 설정·재시도 횟수·경과 시간이 저장됩니다.

서버 동시 요청 수는 같은 서버 주소(프로토콜·호스트·포트)를 사용하는 세션에 함께 적용됩니다. 기본은 2개이며 1~8개 사이로 설정합니다. 대기 중인 세션은 도착 순서로 실행되며 사이드바에서 개별 또는 전체 중지할 수 있습니다. 자동 실행 한도는 첫 자동 대기부터 계산하며 기본 15분입니다. 한도에 도달하면 자동 요청의 대기와 수신을 중지합니다.

모델 연결에서 텍스트·샘플 이미지·샘플 PDF 중 하나를 선택하고 **연결 진단 실행**을 누르면 해당 모델에 테스트 요청 1건을 보냅니다. 진단은 현재 대화나 첨부를 포함하지 않으며, 이미지와 PDF는 샘플 안의 문자 판독 결과도 표시합니다.

## 중단된 실행과 입력 범위

개인 워크스페이스에서는 실행에 사용한 메시지, 모델, 하네스와 완료한 단계를 기기의 복구 저장소에 기록합니다. 앱을 다시 열어 원래 페이지의 **미완료 단계부터 재실행**을 누르면 마지막으로 완료한 단계 다음부터 시작합니다. 수신 중이던 부분 응답을 먼저 확인할 수 있습니다. 재실행은 모델 서버에 별도 요청을 보냅니다. 현재 주소와 모델이 저장 당시와 같아야 하며, 필요한 API 키는 다시 입력할 수 있습니다. 정상 저장 후 해당 실행의 복구 기록을 지웁니다.

**프로젝트 파일 선택**에서 폴더를 열고 파일과 줄 범위를 선택합니다. 선택한 텍스트와 경로가 첨부되며, 전송 미리보기에서 제외할 수 있습니다. 바이트 표시는 선택 텍스트의 UTF-8 크기입니다. 토큰 수와 이미지·PDF 크기는 모델과 서버에 따라 달라집니다.

Builder의 **xcode 단계 지침 내보내기**로 저장한 JSON은 xcode의 **하네스 가져오기**에서 엽니다. Builder 규칙의 이름·지침·열·기준값을 단계 프롬프트로 변환합니다. Builder의 결정적 계산, 조건부 중단은 Builder 실행기에 남습니다.
