## 구현 범위

- 블록 편집은 기본 Markdown 문법·목록·할 일·표를 지원합니다. HTML·프런트매터·첨부 이미지 등 보존이 필요한 확장 문법은 원문 모드를 사용합니다.
- 조직 공동 편집은 별도 Markdown 텍스트 편집 창에서 동작합니다. 일반 편집이 같은 문서를 변경하면 세대를 구분하여 덮어쓰지 않고 사본 보존을 안내합니다.
- 조직 권한은 보관함 단위이며 문서는 해당 권한을 상속합니다. 개인 보관함을 서버에 자동 업로드하지 않습니다.
- Redis는 임시 참여 상태와 변경 알림용입니다. 문서와 공동 편집 상태는 PostgreSQL에 저장합니다.
